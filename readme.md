## 🎯 О чём игра

Это мой первый серьёзный проект — **терминальное казино** с псевдографикой, балансом и рискованными ставками. 

Здесь нет настоящих денег, но есть:
- 🎲 Слот «Угадай число» (рискни 5 рублями)
- 💰 Бесплатное пополнение при нулевом балансе
- 📊 Профиль с балансом
- 🎨 Атмосферный ASCII-арт

Игра написана на **чистом Python** без внешних библиотек.
